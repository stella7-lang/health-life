# 🌱 健康生活小百科

給大學生的飲食、運動、睡眠小知識網站。每一頁只講一個主題，3 分鐘讀完，並附上今天就能做的具體行動。

- 網站連結：https://stella7-lang.github.io/health-life/
- AI 規則文件：[AGENTS.md](AGENTS.md)

## 如何用 AI 新增一頁

對 AI 說：

> 請先讀 AGENTS.md，然後新增一個「飲食」分類的主題頁，主題是「外食族怎麼吃出均衡的一餐」。

AI 會依照 AGENTS.md 第 7 節的步驟：複製模板 → 填入 6 個固定區塊 → 在首頁加卡片 → 更新這份 README。
